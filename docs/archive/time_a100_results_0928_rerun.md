- 同時刻に開始した頂点は、移動時間が最小になる順に並べて復元する

## 5. 所見

- **makespan 型が大幅に安定している。** w20 では n200 まで全実行が到達し、時間窓も w80（72 万項）まで全到達した。w100（125 万項）で初めて崩れる。
- **occupancy 型は n60 から不安定になる。** n60w20 は項数が 4.7 万と小さいのに、制約違反が 6/10 と多い。同じ n60 でも w40 は違反 0 で、項数だけでは決まらない。インスタンスの時間枠の並びに依存していると考えられる。
- **occupancy 型は時間窓幅に弱い。** n60 の w60（48 万項）以上では、実行可能解は出ても既知最良値には届かない（最良 613 対 609、462 対 458、532 対 515）。
- **makespan 型の n40・n60w100 は、目標値より良い解が出ている**（523 対 525、576 対 582）。目標値は「移動時間の既知最良ツアー」の帰着時刻で、makespan の最適値ではないため。
